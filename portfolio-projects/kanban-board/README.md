# Jira delivery reporting

Illustrative Jira-style leadership evidence for delivery risk and release readiness.

![Illustrative Jira delivery management report](evidence/jira-delivery-reporting.svg)

This folder is **not** an automation suite. It holds the screenshot used on the portfolio
to show QA leadership skills: WIP / blocked work visibility, triage dashboards, owners,
and go / no-go decisions.

Sample data only — not a confidential client Jira export.
