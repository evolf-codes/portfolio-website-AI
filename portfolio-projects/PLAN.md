# Portfolio sample plan

Each sample is intentionally small: one credible quality problem, a runnable artifact, and evidence a reviewer can assess quickly.

## Phase 1 — Foundation

- [x] Give all six samples a dedicated folder and focused `SKILL.md`.
- [x] Define an honest status, quality brief, evidence target, and next increment.

Success: every work tile opens a useful brief and only completed work is labelled ready.

## Phase 2 — Samples

- [ ] Complete the AI evaluation sample and failure analysis.

Success: each completed sample runs from a clean checkout and presents reproducible evidence rather than unsupported claims.

## Phase 3 — Release

- [x] Cover portfolio content with unit and browser tests.

Success: unit tests, production build, browser tests, deployment, and production smoke checks all pass.
